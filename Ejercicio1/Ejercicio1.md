# Ejercicio 1

## 1. Crear los archivos 1 y 2

Se crean los archivos `archivo1.txt` y `archivo2.txt`.

![creación de archivos](Imagenes/Imagen1.png)

## 2. Subir los archivos

Se conecta el repositorio local con el remoto usando el comando:

`git remote add origin URL`

Se añaden los archivos con `git add`, se registra el commit con `git commit` y se suben los cambios con `git push`.

![creación de archivos](Imagenes/Imagen2.png)

## 3. Modificar y añadir archivos

Se modifica `archivo1.txt` y se crea `archivo3.txt`. Los cambios se registran con `git add` y `git commit` y se suben con `git push`.

![creación de archivos](Imagenes/Imagen3.png)

## 4. Actualizar el repositorio

Se utiliza `git pull` para descargar los cambios del repositorio remoto y actualizar la copia local de Debian.

![creación de archivos](Imagenes/Imagen4.png)
