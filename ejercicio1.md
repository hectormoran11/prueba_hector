# Ejercicio 1: Git y GitHub

## 1. Crear el repositorio local

Se inicializa el repositorio con `git init` y se establece la rama principal `main`.

## 2. Crear los archivos

Se crean `archivo1.txt` y `archivo2.txt` con contenido de texto.

## 3. Conectar con GitHub

Se conecta el repositorio local con el remoto usando `git remote add origin URL`.

## 4. Subir los archivos

Se añaden los archivos con `git add`, se registra el commit con `git commit` y se suben los cambios con `git push`.

## 5. Modificar y añadir archivos

Se modifica `archivo1.txt` y se crea `archivo3.txt`. Los cambios se registran con `git add` y `git commit` y se suben con `git push`.

## 6. Actualizar el repositorio

Se utiliza `git pull` para descargar los cambios del repositorio remoto y actualizar la copia local de Debian.
